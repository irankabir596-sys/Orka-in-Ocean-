# Binance RSI Scanner

Automated Binance Spot RSI scanner.

## Features

- Top 200 USDT pairs
- RSI 14
- 1H timeframe
- Live candle calculation
- RSI above 60
- RSI below 40
- 30-minute scanning
- RSI descending sorting
- TradingView links
- Telegram subscriptions

## Commands

/start - Subscribe
/stop - Unsubscribe

## Configuration

TELEGRAM_BOT_TOKEN must be configured
in GitHub Actions Secrets.

## Automation

GitHub Actions runs every 30 minutes.
